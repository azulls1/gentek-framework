# Story: Auto-cleanup stale .tmp files

**ID:** STORY-002
**Feature:** `specs/memory-system.md` (v0.4.5)
**Sprint:** S1-bugfixes
**Plan:** `plans/memory-bugfixes.md`

## Story
As **any IAgentek user**, I want **orphan `state.json.*.tmp` files from previous crashes to be removed automatically**, so that **I never have to clean up the `.iagentek/` directory manually**.

## Acceptance Criteria
- [ ] `StateManager.load()` runs `cleanupStaleTmps()` before reading `state.json`.
- [ ] Only files matching the pattern `^state\.json\.\d+\.[0-9a-f]{6}\.tmp$` are touched.
- [ ] Files with mtime <60 seconds old are preserved (could belong to a concurrent live process).
- [ ] Cleanup is best-effort: failures (read-only FS, permission denied) are silenced, never throw.
- [ ] No user-visible output unless DEBUG logging is enabled.
